## Featured Work

### 1. [End-to-End Federated Learning Platform](https://github.com/praneetrajv/FedNas-v3)

A privacy-preserving distributed learning platform where multiple clients collaboratively train a shared model without directly sharing their raw data.

**Key work:**
- FastAPI central server for client registration and training-round management
- Model distribution and aggregation
- Docker-based client training workflows
- PostgreSQL for system data
- Hardware profiling and JWT authentication

**Tech:** `Python` `FastAPI` `Docker` `PostgreSQL` `REST APIs`

---

### 2. [Image Source Detection](https://github.com/praneetrajv/image-source-detection)

Graph-based system for identifying and tracing the source of viral images across social-media-like networks.

**Key work:**
- CLIP-based visual similarity
- Perceptual hashing (pHash)
- NetworkX graph analysis
- Temporal and network-based features
- Image processing using Python and OpenCV

**Tech:** `Python` `CLIP` `pHash` `NetworkX` `OpenCV`

> *SIFT was explored initially during development but is not part of the current approach.*

---

### 3. [Context-Aware AI Reading Copilot](https://github.com/praneetrajv/WordDefiner-extention)

A Manifest V3 Firefox extension that provides context-aware word explanations using Google Gemini REST APIs.

**Key work:**
- Asynchronous DOM extraction
- Dictionary lookups
- Client-side caching
- Contextual prompt generation
- Real-time AI-assisted explanations

**Tech:** `JavaScript` `Gemini` `REST APIs` `Firefox` `Browser Extension`

---

### 4. [DemoGen](https://github.com/praneetrajv/DemoGen)

AI-powered workflow automation tool that converts natural-language instructions into browser-based workflows and generates demonstration videos.

**Key work:**
- LLM-based workflow planning
- Selenium / Playwright browser interaction
- Error detection and replanning
- Automated video generation
- FastAPI backend
- Docker-based deployment

**Tech:** `Python` `FastAPI` `Playwright` `Selenium` `FFmpeg` `Docker`
